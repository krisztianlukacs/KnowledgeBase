prokb 0.3.0 -> 0.3.1 hotfix: kb mcp was broken on fresh installs. (1) What changed: mcp_server.py migrated from mcp.server.fastmcp.FastMCP to mcp.server.mcpserver.MCPServer (mcp 2.x), dependency pinned mcp>=2.3,<3, new smoke test that imports the server and lists its tools. (2) Why: the unbounded mcp>=1.0 resolved to mcp 2.3.0 on the 0.3.0 pipx reinstall; 2.x renamed FastMCP, so every kb mcp start raised ModuleNotFoundError and agents lost the KB MCP tools. No test imported mcp_server, so the suite stayed green. Found by the cross-model bughunt when two repro tests could not import the server. (3) Not changed: tool names, arguments and outputs; query/index behaviour. (4) Impact: KB MCP tools work again after pipx install --force; any machine that installed prokb fresh since mcp 2.x was released was silently without them.
